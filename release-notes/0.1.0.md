- `bbfmodels fetch` downloads any data model document the Forum publishes into a local cache
- `bbfmodels ir` turns a document into JSON with its own schema, readable from any language
- Named data types resolve to their base type and constraints, no second lookup needed
- USP commands, their input and output, and events are part of the model
- A schema indexes TR-181 or TR-098 with service models mounted under Services
- Data paths with instance numbers resolve to the object and parameter they belong to
- A device's values build a tree that reads typed values and writes back exactly what came in
- Vendor parameters the model does not define are kept, never dropped
- Values are checked against ranges, sizes, enumerations, patterns and list bounds

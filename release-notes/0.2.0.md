- Typed pydantic models for TR-181, TR-098 and every service model, installed with the package
- Voice, set-top box, storage, femtocell and Matter models ship in their own packages
- Every object is a class, every parameter a typed field, every table a dict by instance
- `from_flat` builds a model from a device's path and value pairs, `flatten` writes them back
- `problems()` reports every value outside the model's ranges, sizes, patterns and enumerations
- Vendor parameters and objects the model does not define are kept and written back unchanged
- `bbfmodels generate` builds the same models from any document, a vendor's included
- Editors complete the Forum's enumeration values and any other string still validates

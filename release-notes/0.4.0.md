- USP commands and events are typed: a class per command input, output and event payload
- `COMMANDS` and `EVENTS` map a command or event path to its classes, for Operate responses
- Argument values validate like parameters, nested output tables included
- Typed paths name commands and events: `Device.IP.Diagnostics.TraceRoute()`, `Device.Boot!`
- `codec.xsd_type` gives the xsi:type a CWMP SetParameterValues carries
